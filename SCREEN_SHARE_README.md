# Демонстрация экрана со звуком

Реализация демонстрации экрана со звуком на Go с использованием WebRTC.

## Возможности

- ✅ Захват экрана в реальном времени
- ✅ Захват системного звука
- ✅ Передача через WebRTC по локальной сети
- ✅ Современный веб-интерфейс

## Запуск

1. Убедитесь, что у вас установлены системные зависимости:
   - X11 (для захвата экрана на Linux)
   - PulseAudio или ALSA (для захвата звука)

2. Запустите сервер:
```bash
cd video_conference
go run cmd/server/main.go
```

3. Откройте в браузере:
```
http://localhost:8080/screen-share/
```

4. Нажмите "Начать демонстрацию" - экран и звук начнут транслироваться

## API Endpoints

- `GET /screen-share/` - HTML страница для просмотра
- `POST /screen-share/offer` - Создание WebRTC соединения (offer/answer)
- `POST /screen-share/ice/:id` - Отправка ICE candidates
- `POST /screen-share/hangup/:id` - Закрытие соединения

## Технологии

- **Go** - основной язык
- **Pion WebRTC** - WebRTC реализация
- **Pion MediaDevices** - захват медиа
- **kbinani/screenshot** - захват экрана
- **Gin** - HTTP фреймворк

## Примечания

- Для работы требуется X11 сервер (на Linux)
- Звук захватывается с микрофона/системного звука через PulseAudio
- Для работы в локальной сети используйте IP адрес сервера вместо localhost
